# AI-Driven TRPG Game Engine

一个基于大语言模型（LLM）驱动的开放世界 TRPG 跑团游戏引擎。

> **重要提示：目前本游戏仅支持中文游玩！**

---

## 游玩方式

项目支持以下两种运行及游玩方式：

### 方案 A：云端网页版（推荐，即开即玩）
直接访问官方托管链接，无需配置本地 Python 环境：
[点击进入游戏网页](https://kesuluking-trpg.streamlit.app)

### 方案 B：本地部署版
1. 下载本项目核心代码至本地。
2. 确保本地已安装 Python 环境及所需依赖（`streamlit`, `openai`, `httpx`, `supabase`）。
3. 可以在项目根目录下创建一个启动批处理文件驱动程序（推荐使用大模型协助编写）。例如新建一个 `run.bat`，写入以下内容：
```bat
@echo off
streamlit run app.py
pause
```

## 核心操作流程

为了获得最佳的沉浸式跑团体验，请首次进入游戏的玩家按以下流程配置和游玩。

### 1. 配置 DeepSeek API

首次进入且未填写 API Key 时，游戏会自动弹出 **【⚙️ 设置】** 窗口。

在窗口中填写您个人的 **DeepSeek API Key**（通常以 `sk-` 开头）。游戏使用玩家自己的 API Key 调用模型，本平台不进行任何收费。

设置窗口中也提供了 DeepSeek 官方平台与 API Key 页面链接：

- 官方平台：<https://platform.deepseek.com/>
- API Key 页面：<https://platform.deepseek.com/api_keys>

参考消耗：**100次对话≈1元RMB（仅用于API调用）**。建议首次试水充值不超过 10 元。

如果之后需要更换 API Key，可点击左侧边栏的 **【⚙️ 设置】** 重新打开设置窗口。

### 2. 创建或重塑新世界

点击左侧边栏的 **【🌍 新世界】**，打开世界与主角定制窗口。

这里可以设置：

- 世界观大类与具体世界观；
- 主角姓名与背景；
- 身体、心理、经验等初始状态；
- 初始能力、先天特质、背包物品；
- **📚 世界记忆**：用于记录长期背景、世界规则、主角过往等。

世界记忆可以参考以下结构填写：

```text
【世界观】：金庸武侠《笑傲江湖》原著世界。江湖分为正派（五岳剑派、少林、武当）与魔教（日月神教）。武学体系严谨，讲究内功与招数，严禁出现任何修仙、魔法或玄幻元素。当前江湖正因《辟邪剑谱》的传闻暗流涌动。

【当前时间线】：原著开篇。

【主角状态】：我，柯酥卤是一名现代穿越者，原本是20岁男大学生，结果一觉醒来后发现自己穿越了。目前没有武功，但拥有“略知原著全本剧情”的信息优势。

【第一幕锚点】：（可根据个人喜好选填，也可留空）。
```

填写完毕后，点击保存，并选择立即新建会话以应用新设定。

### 3. 开始文字冒险

在主文本输入框中输入您的行动、对白或开局描述。

示例：

```text
我从梦中醒来，还没搞清楚自己的状况，揉着惺忪的睡眼开始打量四周。
```

系统会根据当前世界观、主角状态、NPC 图谱和回合规则生成后续叙事。

### 4. 幕间转场与阶段结算

当一段剧情告一段落时，可以打开主输入框下方的开关：

```text
本轮输入作为【幕间结语】并触发转场结算
```

然后发送本幕最后一句行动或总结。系统会自动完成：

- 本幕收尾叙事；
- 长期记忆摘要；
- 幕间推进与下一幕钩子；
- NPC 图谱更新；
- 必要时同步新世界法则。

转场发送完成后，该开关会自动关闭。

### 5. 世界线管理

左侧边栏提供以下世界线操作：

- **📝 世界赐名**：修改当前世界线的名字。
- **🗺️ 世界线变动**：切换历史世界线。
- **💥 世界线坍塌！**：删除当前世界线。注意：即使后悔药也无法挽回。
- **💊 后悔药**：撤回上一步。

### 6. 查看角色与世界状态

左侧边栏会显示主角状态与 **【遇到的人】**。

普通玩家视图会尽量隐藏内部数值，只显示更适合叙事理解的状态描述、能力名、物品稀有度和个人笔记。

在 **【遇到的人】** 中，玩家可以为每个角色记录私人笔记：

```text
可以在这里记下我对其的印象：
```

这些私人笔记会随世界线保存，但不参与程序计算和模型调用。

### 7. 设置与高级模式

点击 **【⚙️ 设置】** 可以管理：

- DeepSeek API Key；
- **🪽 上帝模式**：开启后放宽系统校验，适合测试或自由创作；
- **🧭 重载世界观威力表**：根据当前世界观重新生成或载入世界法则；
- **🧪 开发者调试模式**：显示后台检定日志、资产变更日志、幕间推进调试等内容。

开发者调试模式可能包含高度剧透风险，首次开启时会要求确认。

### 8. 推荐游玩循环

```text
创建新世界 → 输入行动推进剧情 → 幕间转场结算 → 承接下一幕 → 持续推进世界线
```
