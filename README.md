# AI-Driven TRPG Game Engine

一个基于大语言模型（LLM）驱动的开放世界 TRPG 跑团游戏引擎。

> **重要提示：目前本游戏仅支持中文游玩！**

---

## 游玩方式

项目支持以下两种运行及游玩方式：

### 方案 A：云端网页版（推荐，即开即玩）
直接访问官方托管链接，无需配置本地 Python 环境：
[点击进入游戏网页](https://kesuluking-trpg.streamlit.app)

### 方案 B：本地部署版
1. 下载本项目核心代码至本地。
2. 确保本地已安装 Python 环境及所需依赖（`streamlit`, `openai`, `httpx`）。
3. 可以在项目根目录下创建一个启动批处理文件驱动程序（推荐使用大模型协助编写）。例如新建一个 `run.bat`，写入以下内容：
```bat
@echo off
streamlit run app.py
pause
```

## 核心操作流程

为了获得最佳的沉浸式跑团体验，请首次进入游戏的玩家务必按照以下步骤配置：

### 1. 挂载 API 凭据
* 展开左侧边栏的 **【玩家 API 凭据】** 面板。
* 填入您个人的 **DeepSeek 官方 API Key**（必须以 `sk-` 开头）。系统采用无状态本地会话隔离，您的密钥绝不会上传至服务器。

### 2. 游戏设定定制
* 在 **【会话控制】** 区域中找到 **【游戏设定定制】**。
* 填入您的世界观底层逻辑，点击**保存**并**新建对话**以初始化沙盒。

### 3. 配置外置记忆库
为了让 AI 编织出严谨的剧情，请严格参考以下结构在记忆库输入框中填写：

```text
【世界观】：金庸武侠《笑傲江湖》原著世界。江湖分为正派（五岳剑派、少林、武当）与魔教（日月神教）。武学体系严谨，讲究内功与招数，严禁出现任何修仙、魔法或玄幻元素。当前江湖正因《辟邪剑谱》的传闻暗流涌动。

【当前时间线】：原著开篇。

【主角状态】：我，柯酥卤是一名现代穿越者，原本是20岁男大学生，结果一觉醒来后发现自己穿越了。目前没有武功，但拥有“略知原著全本剧情”的信息优势。

【第一幕锚点】：（可根据个人喜好选填，也可留空）。
```

### 4. 开启文字冒险
* 在主文本输入框中输入您的初始开局剧情。
* **输入范例**：`我从梦中醒来，还没搞清楚自己的状况，揉着惺忪的睡眼开始打量四周。`
* 点击发送，与大模型展开多轮互动推进世界线。

### 5. 触发幕间转场与阶段结算
* 当剧情推进到一定阶段（对话变长、当前事件告一段落）时，如果您希望为其进行阶段性收尾：
* 点击激活 **【本轮输入作为幕间结语并触发转场结算】** 开关。
* 在文本框中输入您本幕的最终行动并发送，系统将自动触发复杂的后台图谱结算、身心状态融合与长期记忆提取。

### 6. 承接下文，循环推进
* 结算完成后，**务必关闭**【幕间结语转场结算】开关。
* 承接上文的结算状态，继续像步骤 4 一样输入新剧情，开启下一幕的冒险。
* 核心游玩循环：`步骤 4 (日常剧情) -> 步骤 5 (幕间结算)`。
